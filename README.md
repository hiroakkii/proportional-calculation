# 比例計算

ブラウザで動く比例計算アプリです。`index.html` をブラウザで開くだけで使えます（インストール不要・外部ライブラリなし）。

## 機能

- **比例式**: `A : B = C : D` のうち3つを入力すると残り1つを求めます。
- **濃縮換算**: 3倍濃縮のレシピを5倍濃縮の調味料で作るときなど、使う量と水の調整量を計算します（大さじ・小さじの目安つき）。
- **希釈**: 濃縮倍率と「原液・水・全量」のどれか1つから、残りの2つを計算します（例：3倍濃縮で全量300ml → 原液100ml＋水200ml）。
- **比例配分**: 合計を指定した比（2つ以上、項目の追加可）で分けます。
- **計算履歴**: 計算結果を最大50件、使っているブラウザに保存します。タップすると入力を復元して再計算します。1件ずつ、またはすべて消去できます。

いずれも計算過程を表示します。小数点以下の桁数は切り替えられます。全角数字やカンマ区切りの入力にも対応しています。
